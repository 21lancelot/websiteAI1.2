Behind the project

“UFC: Two Per Division” re-imagines a landing page template as a curated fan mini-site. Every division shares one data source, making it easy to update contenders, copy, and visuals with a single roster edit and generator run.

Project blurb

This build emphasizes clarity, dark-mode readability, and quick navigation between athletes. A reusable data model fills the home page, division grid, quick browse modal, and auto-generated fighter spotlights so the experience stays consistent while content evolves.

Credits & use

Fonts: Poppins & Inter via Google Fonts (display=swap). Icons: simple inline SVG treatment. Placeholder imagery was generated as abstract silhouettes for educational purposes.

Original layout inspiration: the “Tidy” multi-page HTML template. Styling and components were substantially rebuilt to match the UFC theme.
